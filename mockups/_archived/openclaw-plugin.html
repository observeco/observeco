ClawForge · OpenClaw Runtime Plugin

Intent-aware context loading inside OpenClaw — save 40-60% per turn

@observeco/clawforge-plugin OpenClaw

Drop-in Node.js plugin that hooks into OpenClaw's ContextEngine lifecycle. No config changes — just install and activate.

# Install the plugin
npm install @observeco/clawforge-plugin

# Add to OpenClaw config
{
  "plugins": [
    "@observeco/clawforge-plugin"
  ]
}

# Activate (no restart needed)
observeco clawforge plugin --activate

Architecture

OpenClaw Agent
  └── ContextEngine
      └── [ClawForge Plugin] ← decides what to load/skip at runtime
          ├── bootstrap: load minimal context (SOUL.md + MEMORY.md summary)
          ├── ingest: classify intent → load matching files only
          └── pre-response: estimate tokens → demote low-value content
              └── reports stats to ObserveCo API
                  └── stored in SQLite → dashboard shows savings
