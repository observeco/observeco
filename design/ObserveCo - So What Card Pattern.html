The "So What?" insight card

One small, inline component that turns a raw number into a decision. It rides directly beside the data it explains — never a separate panel. Subtle tint, a 3px tone rule, a mono micro-label, one sentence, and an optional action. This is the layer that makes ObserveCo an observability product, not a data viewer.

Insight

A finding worth acting on, no urgency. Default tone. Green rule.

Watch

Trending the wrong way. Not broken yet. Amber rule.

Alert

Actionable now — breach, trip, or down. Red rule.

Neutral

Context or explanation, no judgment. Slate rule.
