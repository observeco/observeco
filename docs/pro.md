# Pro Features

The free tier of ObserveCo is fully functional for individual developers and small agent fleets. Pro features are available for teams and organizations.

## Free Tier (Always Free, No Limits)

- All CLI commands (`pulse check`, `pulse circuit`, `chisel trim`, `clawforge profile/load/garden`)
- Dashboard with fleet view
- Local SQLite storage
- Unlimited agents
- MIT License — use it anywhere

## Pro Tier ($9/mo Solo, $49/mo Team)

- Alert relay (Telegram, email, webhook push notifications)
- Multi-machine fleet aggregation
- Historical trends (30-day retention)
- Team collaboration (shared dashboard)
- Priority support

> **30-day free trial on all Pro plans.** No credit card required to start the CLI.
