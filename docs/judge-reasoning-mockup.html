UX Design Decisions

  • • Expand on click — reasoning hidden by default, expand per-task. Keeps task list scannable.
  • • Per-assertion breakdown — shows which part of the task failed (regex vs judge vs semantic). Each assertion has its own score chip (pass/partial/fail).
  • • Weighted score bar — visual proportion of pass/partial/fail across all assertions.
  • • Reasoning text — plain-English explanation from the LLM judge. Italics for missing elements, bold for what was found.
  • • Judge metadata — model used, cost, cache status — so users know if the result is fresh or cached.
  • • Passing tasks show no reasoning panel — avoid clutter for tasks that work.
