# ObserveCo Logo Style Guide

**Official brand assets** — last updated September 2026
**Logo concept**: Text-only wordmark — "ObserveCo" in bold serif with a teal period. No icon. Matches the live site at www.observeco.com.

## 1. Primary Logo

- **Mark**: Text wordmark — `ObserveCo.` (bold serif, teal period)
- **No icon**: The older pulse/heartbeat icon was retired with the consulting pivot. The brand is typographic.
- **Source of truth**: The live site header (`<a class="nav-brand">ObserveCo<span class="dot">.</span></a>`)

## 2. Color Palette

| Element | Hex | RGB | Usage |
|----------------------|-----------|-----------------|--------------------------------|
| Word | `#1b1f24` | 27, 31, 36 | "ObserveCo" text (near-black, AA on paper) |
| Period (dot) | `#0e6e5c` | 14, 110, 92 | The trailing "." — insight teal |
| Page Canvas | `#f7f6f3` | 247, 246, 243 | Bond-paper background |
| Hairline | `#e4e2dc` | 228, 226, 220 | Header border |

## 3. Typography

- **Font stack**: `'Iowan Old Style', 'Palatino Linotype', 'Book Antiqua', Palatino, Georgia, 'Times New Roman', serif`
- **Weight**: Bold 700
- **Size**: 19px on the live site (scales with context)
- **Tracking**: Slightly tight (–0.02em)

## 4. Logo Variations

| Variation | File | Use Case |
|-----------------------|---------------------------------------|--------------------------------|
| **Primary (SVG)** | `observeco-logo.svg` | Web, vector, scalable |
| **Primary (PNG)** | `observeco-logo.png` | Raster, docs, presentations |

## 5. Usage Rules

**Do:**
- Keep the teal period — it is the brand's signature accent
- Use the exact word color `#1b1f24` and period color `#0e6e5c`
- Use the serif font stack; do not substitute a sans-serif
- Maintain clear space (minimum = height of the "O")

**Don't:**
- Reintroduce the old pulse/heartbeat icon (retired with the consulting pivot)
- Change colors
- Stretch or rotate
- Use on low-contrast backgrounds
