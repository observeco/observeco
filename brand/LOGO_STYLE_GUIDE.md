# ObserveCo Logo Style Guide

**Official brand assets** — last updated May 2026
**Logo concept**: Pulse line integrated into stylized "Ai" (heartbeat through A + circle as dot on i)

## 1. Primary Logo

- Icon: Green pulse/heartbeat line cutting through "A" with circle as dot on "i"
- Text: "ObserveCo" in clean white sans-serif
- Color: Primary green `#22c55e` + dark navy background `#0f172a`

## 2. Color Palette

| Element | Hex | RGB | Usage |
|----------------------|-----------|-----------------|--------------------------------|
| Primary Green | `#22c55e` | 34, 197, 94 | Pulse line, glow, accents |
| Dark Navy | `#0f172a` | 15, 23, 42 | Backgrounds |
| Text | `#ffffff` | 255, 255, 255 | Logo text (dark mode) |
| Light Text | `#0f172a` | 15, 23, 42 | Light mode text |
| Light Background | `#f8fafc` | 248, 250, 252 | Light mode |

## 3. Logo Variations

| Variation | Use Case |
|-----------------------|---------------------------------------|
| **Primary** | Marketing, website hero, GitHub |
| **Icon-only** | Favicons, app icons, small spaces |
| **Monochrome White** | Dark backgrounds, print |
| **Light Mode** | Light websites, presentations |
| **Horizontal** | Headers, email signatures, banners |

## 4. Typography

- Font: Inter (or system sans-serif: SF Pro, Roboto)
- Weight: Bold 700 for "Observe" and "Ai" integration
- Tracking: Slightly tight (–0.02em)

## 5. Usage Rules

**Do:**
- Keep exact proportions and alignment of the pulse line through "A" + circle dot on "i"
- Use official green `#22c55e` for the pulse
- Maintain clear space (minimum = height of "O")

**Don't:**
- Remove or alter the pulse-through-"Ai" integration
- Change colors
- Stretch or rotate
- Use on low-contrast backgrounds
